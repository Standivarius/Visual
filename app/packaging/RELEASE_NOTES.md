# Visual Alpha

This is an early two-monitor engineering alpha of Visual for low-vision magnification research and Doxa development.

Current alpha capabilities include live GPU magnification on a second display, pointer/caret/focus tracking, viewport following, target locators, zoom hotkeys and exact normal-view return.

Known limitations include incomplete browser-editing compatibility validation, unfinished product UI/settings, unsigned development packaging, and no proven in-app automatic-update flow yet.
